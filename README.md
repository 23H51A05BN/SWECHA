# భారతవాణి (Bharatavāṇi) – Voice of the Mahabharata 📖🎧

A spiritual and educational web application that presents **Bhagavad Gita slokas in Telugu**, along with their **meanings**, **translations**, **summaries**, and **audio playback** (coming soon). This app allows users to explore the wisdom of the **Mahabharata**, starting with Chapter 1 of the Gita.

## 🚀 Getting Started

1. **Install Streamlit**

   ```bash
   pip install streamlit
   ```

2. **Run the app**

   ```bash
   streamlit run app.py
   ```
